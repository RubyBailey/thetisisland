ThetisIsland.net - Communications Route Fix

Purpose
-------
Resolve Astro warning that /communications is generated by both
src/pages/communications.astro and src/pages/[...slug].astro.

Change
------
Replace only src/pages/[...slug].astro with the file supplied here.
The replacement skips the communications content entry when generating
catch-all routes. The dedicated communications.astro page continues to
render src/content/pages/communications.md and its Visitors' Guide link.

Preserved
---------
No changes to Markdown content, Decap CMS fields or config, navigation,
GitHub branches, Cloudflare Workers, or Visitors' Guide configuration.

Installation (from website root)
--------------------------------
1. Back up src/pages/[...slug].astro.
2. Extract this ZIP into the website root, preserving folder structure.
3. Run npm run build.
4. Confirm the /communications conflict warning is absent.
5. Verify dist/communications/index.html exists:
   Test-Path .\dist\communications\index.html
6. Open staging.thetisisland.pages.dev/communications/ after pushing
   changes to the GitHub staging branch and allowing Pages to build.
7. Confirm text, navigation and Visitors' Guide link display properly.
Do not merge staging into main until checks pass.

Note: This patch is based on the ThetisIsland-Review-20261113-164129.zip
upload; compare with your local version if you have edited [...slug].astro
since then.
